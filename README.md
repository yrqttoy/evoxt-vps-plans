跑不动的：编译、视频转码、批量数据处理。单核共享 CPU 做这些事，等待时间会以小时计，不是配置调优能解决的。

## 5 刀机器上手 WireGuard 的两个易错点

安装本身不复杂，`apt install wireguard`、写 `wg0.conf`、`sysctl` 打开转发、UFW 放行 51820 UDP、`wg-quick up wg0` 并设为开机启动，按文档走一遍就成。真正容易出问题的是这两处。

**改完 SSH 配置先别关窗口。** 把 `PasswordAuthentication` 改成 no 并重启 sshd 之后，先在第二个终端窗口用密钥连一次，确认能上去，再关掉当前这个会话。顺序反了就只能去商家控制面板开 VNC 救场。

**客户端 `AllowedIPs` 要写全。** 只写 `0.0.0.0/0` 会漏掉 IPv6。手机在 IPv6 网络下访问时，流量会绕过隧道直接出去，泄漏检查立刻暴露。两段一起写成 `0.0.0.0/0, ::/0`。

还有一个小地方：出网接口名不一定是 eth0，可能是 ens3。用 `ip route show default` 查一下，PostUp 里的 MASQUERADE 规则要对着实际接口写，写错了表现是客户端连上但上不了网。
